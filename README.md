# Library

## Description

Library is a Java-based application designed to manage book inventories and handle user accounts for a library system.

## Features

  - Add, update(buy a book), and delete book records
  - User registration and authentication
  - Add of new users by the user with the administrator role
  - Generating a pdf report of an employee's sales in the last month
  - Role-Based Access Control: Implement security with user roles and permissions
